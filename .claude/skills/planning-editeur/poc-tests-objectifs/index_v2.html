L'objectif au centre, le programme comme véhicule

L'objectif (un test choisi, une cible, une date) est la destination. Le programme est le véhicule qui le sert, l'autorégulation le pilote, les tests les chronos. Entre deux tests, une jauge de préparation monte à chaque séance faite dans la zone, avec une projection honnête à la date : la récompense ne dépend plus d'un test toutes les six semaines.

Questions ouvertes
  • Conflit de mot : en prod, la pastille verte des tests dit « Objectif atteint » (repère de rapport atteint). Avec de vrais objectifs, elle devient « Repère atteint » (ou « Point fort »).
  • Cible proposée : si le test a un repère (rapport entre mouvements, norme du sport), la cible = le repère (front squat → 112,5 kg = cible vs back squat). Sinon, un pourcentage par qualité (table caps-par-sport).
  • Objectifs hors test (régularité, récupération, jour J) : même ligne, même fiche, mais pas d'« Ajouter une valeur » (mesuré par l'app).
  • Préparation = séances faites dans la zone ÷ séances prévues jusqu'ici (séances qui servent l'objectif). Projection = départ + gain visé × préparation, présentée comme une estimation. Jamais une « probabilité » : aucun modèle validé derrière.
  • Jauge, pas anneau : l'anneau reste réservé à l'autorégulation (quoi faire aujourd'hui) ; la jauge dit où tu en es.
  • Objectifs hors test (régularité, récupération) : la préparation suffit, pas de projection chiffrée.
  • Le carrousel de cartes photo reste l'écran de l'onboarding ; dans l'app, la liste est plus dense et lisible.
